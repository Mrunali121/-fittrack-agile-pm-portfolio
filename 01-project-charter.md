# Project Charter — FitTrack MVP

## 1. Project Overview
FitTrack is a mobile application that lets users log workouts, track daily steps, and
build habit streaks with a lightweight, gamified UI. This charter covers the build of a
Minimum Viable Product (MVP) to be released to a closed beta group of 500 users.

## 2. Business Case
User research (12 interviews + a 200-respondent survey) identified strong demand for a
"low-friction" fitness tracker — most competitors were rated as too complex for casual
users. FitTrack targets this gap: log a workout in under 10 seconds.

## 3. Objectives
- Deliver a functional MVP (workout logging, step tracking, streaks) within **6 weeks**.
- Onboard **500 beta users** within 2 weeks of launch.
- Achieve **Day-7 retention ≥ 30%** in the beta cohort.
- Keep MVP scope to **3 core features only** — resist scope creep.

## 4. Scope

**In scope (MVP):**
- Manual workout logging (type, duration, notes)
- Daily step count (via phone sensor)
- Streak tracking + push notification reminders

**Out of scope (post-MVP / backlog):**
- Social sharing / friend feed
- Integration with wearables (Apple Watch, Fitbit)
- Nutrition tracking

- iOS only for MVP (Android post-MVP).
- Budget covers 6 weeks of team time only — no paid user acquisition.
